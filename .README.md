\# Network Traffic Anomaly Detector

ML intrusion detection on CIC-IDS2017 (2.5M flows, 14 attack types).



\## Approach

\- Random Forest classifies known attack types

\- Isolation Forest (benign-only, log-transformed) gives an "unusual traffic" score

\- Streamlit app: upload flow CSV, get attack types plus suspicious flows



\## Results

\- Random Forest: 99.5% accuracy, 99.9% attack detection, 0.16% false-alarm rate

\- Weak classes: Web Attack XSS (F1 0.38), SQL Injection (0.44), Infiltration (0.78)

\- Isolation Forest: ROC-AUC 0.92 but only 2.7% recall at 1% false alarms;

&#x20; 40% at 5%, 71.5% at 10%. It works as a suspicion score, not an alarm.

\- Unseen-attack test: Random Forest generalised better than Isolation Forest

&#x20; (e.g. DDoS 63% vs 7%), though both missed PortScan, Bot and SSH-Patator.



\## Limitations

Random split puts flows from the same attack in train and test, so scores

are optimistic. Rare classes (Heartbleed, SQL Injection) have very few samples.
